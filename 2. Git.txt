Git? Tại sao dùng Git
+ Git được viết bởi Linus Torvalds, cha đẻ của Linux
+ git là từ viết sai chính tả (có chủ đích) của get, do get đã được dùng rồi
+ Dùng git do nhu cầu quản lý phiên bản và làm việc giữa nhiều người với nhau.
So sánh Git & other VCS: CVS, SVN, GIT, Mercural, Bazaar
+ Tính năng: Dễ dùng, có nhiều tính năng vượt trội: branching, tốc độ xử lý nhanh
+ Chi phí: free 
+ Phổ biến: nhiều công ty sử dụng
Phân biệt Git và GitHub
Git: 
+ là 1 phần mềm cài trên máy của Bạn
+ Là một Commandline tool
+ là công cụ quan rlys phiên bản đưa file vào Git repository
+ Có các tính năng của Version control System
GitHub:
+ Là một dịch vụ web, Host trên website
+ Là công cụ có giao diện
+ Là nơi để upload Git repository lên
+ Có các tính năng của Version Control System và một số tính năng khác (bổ sung thêm)
